# Экзо- және эндотермиялық реакциялар · слайд-сабақ (8 сынып)

**Дайын файл:** `exo-endo-sabaq.html` — бір ғана файл, интернетсіз ашылады.
Компьютерге немесе флешкаға көшіріп, екі рет басыңыз (Chrome, Edge, Yandex, Firefox).

## Басқару

| Перне / батырма | Әрекет |
|---|---|
| `→`, `Space`, `PageDown`, ▶ | келесі қадам (анимация, жауап) немесе келесі слайд |
| `↓` / `↑` | келесі / алдыңғы слайдқа бірден өту |
| төмендегі нүктелер | кез келген слайдқа бірден өту (бос дөңгелек — ⭐ қосымша слайд) |
| `←`, `PageUp` | артқа |
| `N` | мұғалім жазбалары (кезең, уақыт, жауаптар) |
| `T` | таймер (ҚМЖ кезеңінің уақыты автоматты қойылады) |
| `S` | топтардың ұпай тақтасы (топ санын, атауын өзгертуге болады) |
| `M` | барлық слайдтар тізімі |
| `F` | толық экран |
| ҚАЗ / РУС / ENG | тілді ауыстыру |
| ☾ / ☀ | қараңғы / ашық фон |

Пульт (presenter) пен интерактивті тақта (саусақпен сырғыту, басу) қолдау табады.
⭐ белгісі бар слайдтар — қосымша, уақыт болса көрсетіледі (жазбаларда көрсетілген).

## Өзгерту

Мәтін `src/slides.html` файлында: `[[қазақша|русский|English]]` түрінде жазылған.
Өзгерткеннен кейін қайта жинау:

```bash
python3 build.py
```
