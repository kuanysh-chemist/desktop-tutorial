# Атом құрылысы. Изотоптар · 7-сынып

**kuanysh.chemist** брендімен жасалған интерактивті слайд-сайт: 22 слайд, ҚАЗ / РУС / ENG тілдері.

## Қалай ашу керек

- `index.html` файлын кез келген браузерде ашыңыз (Chrome, Edge, Firefox, Safari).
- Интернет болса, Unbounded, Nunito және Caveat қаріптері жүктеледі. Интернет болмаса, жүйедегі қаріптер қолданылады.

## Басқару

| Әрекет | Перне |
|---|---|
| Келесі слайд / қадам | `→`, `Space`, `PageDown`, пульт-кликер |
| Алдыңғы слайд / қадам | `←`, `PageUp` |
| Бірінші / соңғы слайд | `Home` / `End` |
| Толық экран | `F` немесе жоғарғы оң жақтағы күлгін «Толық экран» батырмасы |
| Барлық слайдтар тізімі | `M` |
| Квизде жауап таңдау | `1`–`4` |

Телефон мен интерактивті тақтада слайдты саусақпен солға немесе оңға сырғытып ауыстыруға болады.
Жоғарғы оң жақтағы батырмалар тілді ауыстырады, дыбысты өшіреді және толық экранға шығарады.

## Өзгерту

Бастапқы файлдар `src/` бумасында. Өзгерткеннен кейін `python3 build.py` іске қосыңыз.
Ол `index.html` файлын және `dist/artifact.html` файлын қайта жинайды.
