# Химиялық тепе-теңдік — слайд-сайт (10-сынып)

Бір өзі тұратын `index.html` файлы. Интернетсіз де жұмыс істейді (қаріптер мен дыбыстар ішінде).

**Ашу:** `index.html` файлын браузерде ашыңыз (қос шерту).

## Басқару

| Әрекет | Қалай |
| --- | --- |
| Келесі / алдыңғы слайд (немесе қадам) | `→` `←`, `Space`, `PageDown` / `PageUp`, экрандағы жебелер, телефонда сипау |
| Мазмұн (барлық слайдқа өту) | `M` немесе ☰ түймесі |
| Толық экран | `F` |
| Дыбыс қосу/өшіру | `S` (бастапқыда өшіп тұрады) |
| Нақты слайдқа сілтеме | мекенжайдың соңына `#12` қосыңыз |

Слайдтардағы түймелер, слайдерлер мен колбалар интерактив: оқушылар концентрацияны, қысымды, температураны өздері өзгертіп көреді.
