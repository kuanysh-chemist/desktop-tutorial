# Металдар және қорытпалар — слайд-сайт (9-сынып, химия)

Екі тілді (қазақша / орысша) интерактивті сабақ. Түпнұсқа: «Металлы. Сплавы металлов» (40 слайд). Сайт 37 экраннан тұрады, әр қасиет анимациямен және симуляциямен түсіндіріледі.

## Қалай ашу

| Тәсіл | Қалай |
|---|---|
| Бір файл (интернетсіз, флешкаға салуға болады) | `dist/metaldar-sait.html` файлын браузерде ашыңыз |
| Папка | `index.html` файлын браузерде ашыңыз |

Проекторда: **F** — толық экран. Телефонда экранды көлденең ұстаңыз.

## Басқару

| Әрекет | Пернетақта | Сенсор / тышқан |
|---|---|---|
| Келесі / алдыңғы экран | `→` `←`, `Space`, `PageDown` / `PageUp` | төменгі жақтағы дөңгелек батырмалар, саусақпен сырғыту |
| Тіл ауыстыру | `L` | жоғарғы оң жақтағы **ҚАЗ / РУС** |
| Мұғалім панелі (Ұста) | `T` | төменгі сол жақтағы кішкентай Ұста белгішесі |
| Мазмұн | `M` | жоғарғы оң жақтағы төртбұрыш белгіше |
| Толық экран | `F` | жоғарғы оң жақтағы белгіше |
| Жабу | `Esc` | |

Әр экранның астында келесі тақырыппен **байланыстыратын сөйлем** бар: оны басса, келесі экранға өтеді. Оң төменгі бұрыштағы көк белгі — «Сен білесің бе?» карточкасы.

## Ұста — мұғалімге көмекші

Баланың назарын аудармайтындай кішкентай, бұрышта тұрады. Басқанда үш қойынды ашылады:

* **Жазба** — әр экранға әдістемелік кеңес, демонстрация, түсіндіру (түпнұсқа слайд жазбалары негізінде);
* **Жауаптар** — тест пен тапсырмалардың жауабы;
* **Сөздік** — қиын терминдердің қысқа анықтамасы (іздеуге болады).

## Мазмұны (7 тарау)

1. **Кіріспе:** титул, жұмбақ (күміс кубогы), мақсаттар.
2. **Құрылым:** периодтық жүйе, металдық байланыс (қадамдап), кристалл тордың түзілуі (Демонстрация № 4), кристалл торлардың үш түрі (оқулықтағы атаулар, 3D), тор → қасиет.
3. **Физикалық қасиеттер:** пластикалық, электр- және жылуөткізгіштік (әр металды тексеру, тұйық тізбек), жылтыр, тығыздық (таразы және «неге ауыр?» құрылыс анимациясы), балқу, қаттылық, магниттік қасиет, тапсырма.
4. **Химиялық қасиеттер:** тек тотықсыздандырғыштар, оттегі/хлор/су, виртуалды зертхана.
5. **Қорытпалар:** анықтама (Демонстрация № 5), құрылым, неге берік, салыстыру, шойын мен болат, карточкалар, ойын, жаңа қорытпалар.
6. **Металл алу:** рудадан металға, домна пеші мен конвертер.
7. **Қазақстан:** кен орындары картасы, өндіру мен экология, металлургия және жаңа жобалар, өндірістік тізбектер.
8. **Қорытынды:** «Сен білесің бе?» (22 фактінің бәрі бір бетте, анимациямен), өзіңді тексер, сабақ қорытындысы.

## Файл құрылымы

```
index.html          негізгі бет (ол скрипттерді тізбектей жүктейді)
css/style.css       стиль (түстер — :root айнымалыларында, қараңғы тақырып бар)
fonts/              Nunito (кириллица, қазақ әріптері үшін)
js/core.js          ядро: навигация, тіл, мұғалім панелі, анимация құралдары
js/data.js          Ұста суреті, белгішелер, сөздік
js/data-map.js      Қазақстан картасының контуры
js/s-*.js           слайдтар (тараулар бойынша)
tools/build.py      бір файлға жинау → dist/
```

## Мәтінді өзгерту

Әр мәтін екі тілде жазылады: `L('қазақша', 'орысша')`. Мысалы:

```js
html: () => `<p class="t">${L('Металдар жылтырайды', 'Металлы блестят')}</p>`
```

Жаңа экран қосу: `Deck.add({ id, ch, t:[kk,ru], note:[kk,ru], html(){…}, init(root){…} })`, ал `index.html` ішінде скриптті қосыңыз. Өзгерістен кейін бір файлды жаңарту үшін:

```bash
python3 tools/build.py
```

## Ескертпелер

* Қазақша мәтінді оқулықтағы терминдермен салыстырып шығу ұсынылады.
* Қазақстан картасы — схема: маркерлер кен орнының шамамен орнын көрсетеді.
* Санды деректер (қаттылық, температура, тығыздық, өндіріс көрсеткіштері) түпнұсқа слайдтан алынған; «Сен білесің бе?» карточкаларының бір бөлігі оқулықтан.
* Ескендір (А. Македонский) туралы оқиға — жиі айтылатын тарихи аңыз; күмістің бактерицидтік қасиеті — дәлелденген факт.
