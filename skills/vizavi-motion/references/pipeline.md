# Пайплайн: от пустой папки до проверенного MP4

Готовые инструменты лежат в `scripts/` скилла (далее `$SK`). Используй их, а не пиши движок, рендер и звук заново — это экономит часы и уже содержит исправления типичных ошибок. Меняй и расширяй их под задачу свободно.

## 1. Структура проекта

```
project/
  index.html          ← $SK/engine/template.html
  engine/core.js      ← $SK/engine/core.js   (камера 2.5D, слои, DOF/смаз, частицы, свет, иней, зерно, морф, пальцы)
  engine/text.js      ← $SK/engine/text.js   (субтитры по словам, titleReveal, maskReveal)
  fonts/              ← python3 -I $SK/fetch_fonts.py project/fonts "Cormorant:wght@500=Corm" …
  timeline.js         ← vo.py (window.TL с таймингами слов); без озвучки можно не создавать
  scenes.js           ← твой фильм (пример: $SK/engine/demo-scenes.js)
  audio/score.py      ← партитура на $SK/audio/synth.py (пример: score_example.py)
```

## 2. Контракт renderAt(t)

`scenes.js` задаёт `window.DURATION`, `window.FONTS` и `window.renderAt = makeRenderer(scenes, {dissolves, overlays, texts})`. Каждый кадр рисуется заново только из `t`: без накопленного состояния, без `Math.random()` (используй `rng(seed)`, `hash`, `fbm`). Тогда кадры можно рендерить в любом порядке, параллельно, с перемоткой — и превью совпадает с экспортом.

Сцена = функция `t → кадр`: камера `cam(t)` (и `cam(t - 1/60)` для смаза), слои от дальнего к ближнему, частицы, свет, `grade`, `post`. Склейки и общие наложения (вспышки, иней, шторки) — в `overlays(t)`, текст — в `texts(t)`.

## 3. Порядок работы и команды

1. Скопируй шаблон, скачай шрифты, вставь сцены по раскадровке.
2. **Замер скорости**: `node $SK/render.js --page index.html --bench` → мс/кадр и прогноз времени. Если прогноз > 30 мин, упрощай (см. §4) до полной сборки.
3. **Стайлфреймы**: `node $SK/render.js --page index.html --stills st 3 12.5 30 …` → смотри JPG, правь по [крафту](craft.md). Повторяй до прохождения гейта.
4. **Звук**: `python3 -I $SK/audio/vo.py lines.tsv vo/` (озвучка + тайминги слов) → `audio/score.py` на `synth.py` → `mix.wav` (+ стемы и `mix_accents.json`).
5. **Черновой рендер** частями или целиком: `node $SK/render.js --page index.html --out draft.mp4 --audio mix.wav [--from 20 --to 32]`.
6. **Проверка**: `bash $SK/review.sh draft.mp4 rev <таймкоды склеек…>` → `probe.txt`, `sheet_*.jpg` (кадр каждые 0.5 с), `cuts.jpg` (кадры вокруг склеек), `spectrum.png`, `transcript.txt`. Прочитай все листы, запиши дефекты (интервал → наблюдение → причина → правка), исправь, перепроверь изменённые места.
7. **Финал**: полный рендер → снова `review.sh` → выдача (`SendUserFile`/путь) с честными статусами.

Requires: Node + Playwright с Chromium (`require('playwright')`), ffmpeg, Python 3 + numpy/scipy; для голоса `pip install piper-tts faster-whisper`. Ставь только недостающее.

## 4. Производительность

Ориентир: 0.6–1.1 с/кадр на воркер при 1080p с размытиями; 4 воркера → ~20 мин на 85 с при 60 fps. Самое дорогое — `ctx.filter = blur()` на полнокадровых буферах (`layerFX` с blur, `bloom`, `lightShaft`): держи их ≤ 4–5 на кадр. Повторяющееся (деревья, горы, текстуры) запекай один раз через `bake`/`ridgeSprite` и рисуй `drawImage`. Частиц 500–1300 на поле — нормально.

## 5. Звук и голос

- Если у пользователя есть трек или лицензированная библиотека — используй её; `synth.py` — запасной путь и средство для звукового дизайна, синхронного с кадром.
- Пиши мотив (3–6 нот в ладу из `MODES`) и развивай его по актам; тишина 0.3–1.5 с перед главным ударом (`Mix.silence`); эффекты — на контакты и переходы, не на каждый бит.
- Озвучка через Piper звучит синтетически — так и сообщай. `vo.py` печатает, что распознаётся в каждой фразе: искажённые слова (имена, ударения) переформулируй, знак `+` для ударения Piper зачитывает вслух.
- `Mix.render` приглушает музыку под голосом, нормализует громкость (−16 LUFS, пик −1.5 dBTP) и пишет стемы. После сведения проверь разборчивость по `transcript.txt` из `review.sh`: если фраза в миксе распознаётся хуже, чем отдельно, — громкий инструмент мешает в этот момент (сдвинь, приглуши, убери удар с ключевого слова).
- Распознавание по музыке без речи «галлюцинирует» (выдаёт выдуманные титры) — для таких роликов `transcript.txt` не показатель.

## 6. Ловушки (реальные дефекты прошлых сборок)

| Симптом | Причина | Решение |
|---|---|---|
| Слова субтитров наезжают друг на друга после титра | `textAlign='center'` и др. состояние canvas осталось от другой сцены | `reset()` в начале каждого блока рисования (в движке сбрасывает и текстовые свойства) |
| В интерьере пол закрывает тени и людей у стены | горизонт пола взят на бесконечности (центр экрана) | `groundPlane(..., D0 = глубина задней стены)` |
| Передний объект исчезает при наезде | `D − z` стал мал, масштаб огромный | глубина переднего плана ≥ z_max + 300 или компенсируй по x |
| Чёрные углы на крупном плане | поворот/уменьшение кадра, фон нарисован впритык | фон с запасом ×2.5 |
| Грязное пятно в центре при инее | прозрачный центр маски на тёмной сцене | haze ≥ .6 у пика `frostLens` |
| Горы/фон обрываются краем спрайта | спрайт уже обзора камеры | `drawRidge` тайлит и заливает низ; для своих спрайтов — запас по ширине |
| Огромная тёмная масса в нижней половине | гребни слишком высоко, камера низко | сначала стилкадры композиции, гребни/горизонт на 55–70% высоты |
| Длинная строка вылезает за край | нет переноса | `captions` переносит при > 80% ширины |
| Огонь синий, когда не должен | непрерывный параметр «холод» использован как bool | порог или смешивание цвета |
| Рендер «зависает» без вывода | первые кадры медленнее (запекание спрайтов, шрифты) | смотри лог воркеров, `--bench` до запуска |
| 20 с на кадр вместо 1 с | `ctx.filter = blur()` на каждом штрихе (пар, дым, волосы) | рисуй все штрихи прохода в один буфер и размывай его один раз: `layerFX(g => {…штрихи…}, {blur, comp:'screen'})` |
| Полсекунды пустого однотонного экрана на переходе | вспышка/дымка с пиком 1.0 и длинным плато | пик ≤ .8, плато ≤ .2 с; сквозь дымку должна проступать следующая сцена |
| Сцена целиком чёрная / «дырка» в маске не вырезается | `ellipse(…, 0, 6.28, true)`: против часовой и конец < 2π рисует почти нулевую дугу | всегда `Math.PI * 2`; перед вторым контуром в том же пути — `moveTo` |
| Герой не читается в общем плане | персонаж < ~¼ высоты кадра, тёмный на тёмном | в повествовательных планах герой крупнее; контровой свет или тёплый/холодный контраст с фоном |
| Персонажи «прозрачные», сливаются со стеной | тон персонажа ≈ тону фона | светлее/контрастнее фона + светлое брюшко/морда + rim |
| Голос глохнет на ударе | удар/инструмент на ключевом слове | двигай акцент, `Mix` уже приглушает музыку, но не удары в sfx — снизь их |
