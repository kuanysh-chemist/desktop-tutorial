# Юки-онна — motion-ролик по японской легенде

Короткий 2D-фильм (≈84 с, 1920×1080, 60 fps) в эстетике разобранного референса
(by_anna.ai, «Ямамба»): тёмная народная сказка, палитра «ночной бирюзовый × красный акцент × огонь»,
хук-логлайн в начале, переходы через предмет и кольцевая концовка. История — своя: легенда о Юки-онне
(снежной женщине), которая сдержала слово, когда человек своё нарушил.

Всё изображение рисуется кодом (Canvas 2D), музыка и шумы синтезируются (numpy/scipy),
озвучка — офлайн-TTS (Piper, голос `ru_RU-irina-medium`).

## Состав

- `index.html` — плеер/рендер-страница (`?t=12.5` — один кадр, без параметров — проигрывание).
- `src/core.js` — камера 2.5D с параллаксом, DOF, снег с motion blur, иней на объективе, зерно.
- `src/art.js` — персонажи и предметы (Юки, путники, хижина, огонь, вагаса, глаза, губы, пальцы, камелия).
- `src/scenes.js` — 13 сцен, переходы, кинетические субтитры.
- `timeline.json` / `src/timeline.js` — реплики с пословными таймингами.
- `audio/build_audio.py` — музыка (хирадзёси: кото, сякухати, тайко, дроны), SFX и сведение с VO.
- `audio/vo/` — фразы озвучки.
- `storyboard.md` — раскадровка с вариантами по сценам.
- `tools/render.js`, `tools/stills.js` — покадровый рендер через Playwright/Chromium.

## Сборка

```bash
python3 -I audio/build_audio.py audio/vo timeline.json /tmp/mix.wav
node tools/render.js /tmp/part0.mp4 0 1260      # и т.д. по диапазонам кадров (всего 5040)
ffmpeg -f concat -i parts.txt -i /tmp/mix.wav -c:v libx264 -crf 16 -pix_fmt yuv420p -r 60 -c:a aac -b:a 256k yuki-onna.mp4
```
