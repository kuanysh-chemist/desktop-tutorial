# Пилот «Сера, которая становится резиной»

Вертикальный ролик 1080×1920, 60 кадров/с, 46 с, с озвучкой, музыкой и субтитрами. Проверка связки двух стилей из каталога (`style-catalog/ANALYSIS.md`): гравюра XIX века (№ 26) для истории и синяя сетка с HUD (№ 21) для механизма.

## Химия (проверено по справочным данным)

- Ромбическая сера — кольца S₈ («корона»); плавится около 113–119 °C в подвижную жёлтую жидкость.
- Около 159 °C (λ-переход) кольца раскрываются и полимеризуются в длинные цепи; вязкость растёт примерно с 0,007 до ~93 Па·с к 187 °C, то есть больше чем в 10 000 раз. Цвет темнеет до красно-бурого.
- Если вылить горячую серу в холодную воду, получается пластическая (аморфная) сера — тянется, как резина. За часы или дни она снова кристаллизуется в хрупкую серу из колец S₈.
- Не все кольца раскрываются, поэтому в кадре часть колец остаётся целыми.

## Структура

- `src/img/A.jpg`, `B.jpg`, `C.jpg` — гравюры, сгенерированы Canva AI по STYLE-блоку № 26.
- `src/scenes.js` — весь фильм: съёмка гравюр, сетка, молекулы, HUD, переходы, титры.
- `src/engine/` — движок vizavi-motion (core.js, text.js; в text.js подложка субтитров теперь поднимается вслед за высоко поставленными субтитрами).
- `audio/lines.tsv` → `audio/vo.py` — озвучка Piper (ru_RU-irina-medium, синтетический голос) с проверкой распознаванием.
- `audio/build_audio.py` — музыка и звуковой дизайн, микс −16 LUFS.
- `tools/render.js` — рендер в MP4; `tools/review.sh` — проверка экспорта.

Сборка:

```
cd audio && python3 -I vo.py lines.tsv vo --speed 1.0 && python3 -I build_audio.py out/mix.wav && cd ..
cp audio/vo/timeline.js src/timeline.js
node tools/render.js --page src/index.html --out out/sera_pilot.mp4 --audio audio/out/mix.wav
```
