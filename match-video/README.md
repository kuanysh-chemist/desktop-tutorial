# Сіріңке тарихы — анимация (p5.brush)

12 сахналы сценарий бойынша тік (9:16, 1080×1920, 24 fps) анимация.
Суреттер [p5.brush](https://github.com/acamposuribe/p5.brush) кітапханасымен салынған:
қарындаш сызықтары, акварель құйылымдары, штрихтар. Сызықтар секундына 12 рет қайта салынады,
сондықтан қолмен салынған анимация сияқты «тірі» дірілдеп тұрады.

## Іске қосу

Алдын ала қарау (браузерде, видеокартамен жылдам жұмыс істейді):

```bash
npx http-server match-video -p 8080
```

содан кейін `http://localhost:8080` ашыңыз. Сахна нөмірінің түймелері, жүгірткі және «Ойнату» түймесі бар.

MP4 рендер (Playwright + ffmpeg керек):

```bash
node match-video/render.mjs
```

Нәтиже: `match-video/out/siringke.mp4`. Бөлігін ғана рендерлеу: `--from 10 --to 20`; жеке кадрлар: `--stills 1.5,30`.

## Файлдар

- `src/kit.js` — сурет құралдары: кейіпкерлер, қолдар, сіріңке, жалын, колба
- `src/scenes.js` — 12 сахна (уақыт, камера, жазулар)
- `src/engine.js` — уақыт желісі, жарқырау, мәтін, өтулер
- `lib/brush.js` — p5.brush 3.0.0 (MIT лицензиясы, `lib/p5.brush-LICENSE.md`)
- `fonts/` — Caveat және Rubik қаріптері (SIL OFL), қазақ әріптерімен
